## Stories involving NPC behavior, both in and out of combat

| NPC Combat Behavior User Stories |
| ------------------- |
| As an NPC, I want my combat actions determined by my existing behaviors so that I have a sequence of actions to execute during combat.|
| As a Designer, I want NPC combat behaviors to be reusable and interchangable in order to ease the creation of multiple NPCs for an encounter.|
| As an NPC, I want to use environmental information to make decisions so that my options are optimal for the situation.|
| As a Designer, I want to ensure that all number systems affect NPCs the exact same way user characters are affected to create a sense of fairness.|
| As a Designer, I want NPCs to be able to use different classes so that their combat style is unique.|
| As a Designer, I want to know exactly how NPCs are assigned behaviors so that I can control exactly what behaviors are added.|
| As an Room, I want the ability to store NPC data of the MOBs within my area so that they can be loaded in fast once a player enters me.|
